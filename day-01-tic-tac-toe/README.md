# Day 01 - Tic Tac Toe

A simple Tic-Tac-Toe game built with React as part of my React practice.

## What I Practiced

- React components
- Props
- useState
- Event handling
- Updating state
- Conditional rendering
- Winner calculation

## Features

- Play as X and O
- Alternates between players
- Prevents selecting an occupied square
- Detects the winner
- Displays the next player

## Run the Project

npm install
npm start
